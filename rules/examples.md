# Bullet Examples

Original examples for data and tech roles, following the patterns in the sources. The source originals are in `Resume_cv optimizer workflows/`: the Jeff Su toolkit's "Bullet-Point Examples" and the optimiser's "Example Tone Reference".

## XYZ anatomy (BUL-01)
Accomplished **X** (what changed), as measured by **Y** (the number), by doing **Z** (how).
> Cut weekly sales reporting from 6 hours to 45 minutes (X + Y) by rebuilding 12 Excel reports as one Power BI dashboard on Snowflake (Z).

## Responsibility → impact (BUL-04)
- Weak: Responsible for building dashboards for the sales team.
- Strong: Cut weekly sales reporting from 6 hours to 45 minutes by rebuilding 12 Excel reports as one Power BI dashboard on Snowflake.

## Keyword stuffing → keyword mapping (KW-02)
- Weak: Experienced in data pipelines, ETL pipelines, data engineering and pipeline orchestration.
- Strong: Reduced failed nightly loads from 9 a month to 1 by moving 14 ETL jobs to Airflow with retries and alerting.

## Raw notes → bullet, same facts (BUL-05, EVD-03)
- Raw notes: finance kept asking the same churn questions, like 20 a week. wrote a data dictionary + FAQ, now it's maybe 3 a week
- Weak (generic AI): Spearheaded cross-functional data literacy initiatives to drive stakeholder alignment.
- Strong: Lowered ad-hoc churn questions from finance from about 20 to 3 a week by publishing a data dictionary and FAQ.

## Listing AI → proving AI (AI-01, AI-03)
- Weak: Skills: ChatGPT, Claude, prompt engineering.
- Strong (workplace): Cut monthly ticket analysis from 3 days to 4 hours with a Python tool that uses an LLM API to tag support tickets by theme.
- Strong (independent project, under PROJECTS with a link): Built a Python tool that uses an LLM API to tag 4,000 public support tickets by theme, checked a sample by hand and published the results on GitHub.

## No metric available (BUL-09)

## Derived numbers (EVD-03)
If the evidence says "6 hours to 45 minutes", don't write "cut reporting time by 87%" unless the user confirms that figure and it's added to the profile's metrics.
